Explicacion de archivos:

Los archivos o carpetas que digan "testing" son solo pruebas que para funcionamientos especiales, no tiene efecto en el proyecto.

Funcionamiento:

1-Se ejecuta el código del backend
2-Se ejecuta el script del raspberry que debe estar dentro del mismo.
3-Se sube y ejecuta el código del sensor
4-La aplicación solo necesita el backend ejecutandose para funcionar.
